# Shortcuts

| Shortcut | Action |
|---|---|
| Alt + L | Toggle laser pointer |
| Left Click Hold | Draw |
| Alt + C | Clear all drawings |
| Alt + U | Undo last stroke |
| Alt + Up | Increase thickness |
| Alt + Down | Decrease thickness |
| Ctrl + Q | Quit |

Each app shortcut uses at least two buttons: one selected modifier and one selected key. The modifier is user-selectable; it is not forced to Ctrl + Alt.
