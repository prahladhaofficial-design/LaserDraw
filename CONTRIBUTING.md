# Contributing

Thanks for helping improve LaserCursor.

## Development

Requirements:

- Windows 10 or newer
- .NET 8 SDK

Build:

```powershell
dotnet build .\LaserCursor.sln
```

Run:

```powershell
dotnet run --project .\src\LaserCursor\LaserCursor.csproj
```

## Pull Requests

- Keep changes focused.
- Test cursor restore before submitting.
- Avoid changes that require administrator permissions for normal use.
- Update README/docs when changing shortcuts or release behavior.
